# Security boundaries and remaining work

The verified JWT is the only company identity. Required claims include user_id, employee_id, company_id, role, iat, exp, iss and aud. HS256 is explicitly allowlisted; issuer/audience/time/signature and role checks run on every protected request. Demo minting is a development-only local command, never an API. Store the signing secret separately from client access tokens. Short expiration limits but does not implement revocation.

Request models forbid extra fields. Uploads accept only one file form field. Tenant query overrides are rejected; unrelated headers cannot change tenant. Every administration lookup includes the authenticated company and returns 404 for a foreign version. Feedback additionally verifies answer ownership. The model sees at most the authenticated tenant/version and cannot call tools. Malicious user or document instructions cannot widen backend retrieval.

Vector predicates include company and version; evidence membership, content and metadata are independently compared to SQLite. The provider returns chunk IDs only; source references come from validated originals. Exact quotations are required; invented wording, fabricated IDs, stale versions and foreign citations fail validation. One correction is allowed, never more than two HTTP invocations. Non-answer/clarification messages are composed by the backend.

TXT/PDF/DOCX signatures, size/content/page limits, encrypted PDFs, DOCX expansion sizes and macro/embedded-object checks are enforced. A bounded ASGI body reader rejects oversized raw requests before multipart parsing, including chunked bodies: upload file limit plus 64 KiB multipart overhead, and 16 KiB for other write requests. A proxy should add connection/time limits against slow uploads. This is not antivirus or a parser sandbox. HTTPS, secret management, dependency updates, parser hardening, token revocation, threat modeling, employee-data privacy review and penetration tests remain deployment responsibilities.

Frontend uses same-origin requests, a restrictive CSP, no HTML injection from data and in-memory JWTs. Session switches abort requests and clear output. Server logs omit tokens, prompts, response bodies and secret values. Audit stores tenant-scoped lifecycle events and actor IDs. Feedback reasons are bounded user text; access/retention needs a real organizational policy. Uvicorn access logging is disabled in provided commands to avoid query-string leakage.
